# Documentation pour la génération de tickets
Pour lancer la génération du ticket rentrer la commande suivante:
Python3 main.py “But Maket” “Lisa” “C01:10|C02:2”
Avec "But Maket" étant le nom du magasin, "Lisa" étant le nom du serveur et "C01:10|C02:2” étant la liste de produits, un "|" entre chaque produit. Le C01:10 de l'exemple est le code du produit suivit de ":" suivit de la quantité.
